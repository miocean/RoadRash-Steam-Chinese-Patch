# 暴力摩托 Steam 简体中文补丁

适用于 **Road Rash: 30th Anniversary Edition（30周年纪念版）Steam 英文版**的非官方简体中文补丁。

**[下载 EXE 安装器（最新发布）](https://github.com/miocean/RoadRash-Steam-Chinese-Patch/releases/latest)**

## 安装与还原

1. 退出游戏，在 Steam 游戏属性中将语言设为 **English**。
2. 在 Releases 下载 `RoadRash_Steam_ZH_v1.3.exe`，双击打开。
3. 点击“浏览…”选择游戏目录，或直接粘贴路径。应选中包含 `RoadRash95.exe` 和 `TEXT` 文件夹的根目录。
4. 点击“检查目录”，确认版本匹配后点击“安装汉化”。
5. 从 Steam 正常启动游戏。

需要还原时，退出游戏，用同一安装器选择相同目录，点击“还原英文”。原始文件备份在游戏目录的 `Codex-ZH-backup-v1/ENU.DLL`，请保留。

安装器会校验游戏版本、内置补丁和原始备份，遇到不匹配的文件会停止。替换 `TEXT/ENU.DLL`，并从你已有的原版立绘生成24个中文文件名副本，修复生涯闲聊立绘。保留原图和游戏主程序。还原时仅清理安装器创建且未被改动的副本。兼容v1.0至v1.2备份。

## 汉化范围

- 977条译文，其中包含480条人物对话。v1.3逐条重审480条闲聊，补回俚语、挖苦、双关和上下文信息；相较v1.2共修改558条。
- 主要菜单、人物介绍、赛道提示、车辆介绍、设置、比赛与结算提示。
- 部分制作名单标题和职务。

车辆品牌和型号、乐队和歌曲名、制作人员姓名、版权与音乐授权文字保留原文。图片招牌、视频画面和语音未改动；不含视频字幕或中文配音。部分由主程序提供的系统文字可能仍为原文。

## 兼容性与验证

针对2026年11月6日制作时的 Steam 周年版文件进行适配，安装器使用SHA256校验具体版本。需要简体中文非 Unicode 程序环境（系统代码页936）。v1.3会拒绝1252、UTF-8/65001等其他代码页下的安装，防止游戏乱码；还原英文不受此限制。安装器不会更改系统区域设置。

## 源码与构建

`src/` 为 C# Windows Forms 安装器源码，`translations/` 保存译文，`payload/ENU.DLL` 为已翻译的语言资源，构建时会嵌入EXE。

Windows 自带的 .NET Framework 4.x C# 编译器可用于构建：

```powershell
./build.ps1
```

输出：`dist/RoadRash_Steam_ZH_v1.3.exe`。无需额外安装打包工具。译文表用于审校和后续维护；修改译文表后需要重建语言资源，并同步安装器中的补丁摘要。

## v1.3补充说明

车手采用庄臣、戴维、汤姆、露西亚、杰斐逊、姆克迪、塞利娜、迈克等旧译名，对话称呼同步统一。旧版译名参考[玩家回顾文章](https://www.sohu.com/a/324464227_120099885)和[旧版五级攻略](https://www.962.net/gl/73413.html)。国内旧汉化有异体字和译名差异，本项目统一采用 `translations/character-names.json` 的写法。

刘沛松是旧版流传存档里的玩家名，使用记录可见[玩家视频说明](https://www.bilibili.com/video/BV1v54y1s736/)。安装器默认勾选“昵称为空时设为刘沛松”，可取消。仅在当前用户的游戏昵称为空时写入，已有昵称保留；还原语言不会重置昵称。不附带旧存档，不改生涯进度。游戏界面“别名”改成“玩家：”，避免与NPC姓名混淆。

原版已经有闲聊立绘。汉化后的短姓名被用于拼接 `Chars/姓名-表情` 图片路径，从而找不到原来的英文文件。v1.3按24项摘要清单复制对应原图，不重新绘制、不分发原始图片。在本机独立完整副本中抽查了五位说话车手，覆盖友好、中立、敌对表情；人物介绍、玩家昵称、车行长说明显示完整。未逐条人工查看480条闲聊或完整通关。

重建语言资源：`node build-language.cjs <英文原版ENU.DLL路径>`。构建器校验原件摘要；修改译文后还需同步 `build.ps1` 和 `src/Installer.cs` 的PayloadHash。安装器继续由 `build.ps1` 构建。
重点双关、俚语和翻译取舍见[译注](translations/译注.md)。部分台词按语境采用少量现代中文玩家用语。
