# 暴力摩托 Steam 简体中文补丁 v1.5

汉化作者为 **miocean-晓风**。适用于 Road Rash 30周年纪念版 Steam 英文版。

[下载最新正式版](https://github.com/miocean/RoadRash-Steam-Chinese-Patch/releases/latest)

## 安装与升级

1. 退出游戏，将 Steam 游戏语言设为 English。
2. 下载并运行 RoadRash_Steam_ZH_v1.5.exe，选择包含 RoadRash95.exe 和 TEXT 文件夹的游戏目录。
3. 点击“检查目录”，勾选需要的可选功能，再点击“安装汉化”。

安装器识别的旧版可直接覆盖安装。升级时重新勾选需要保留的可选功能。请保留 Codex-ZH-backup-v1 原版备份。遇到未识别的文件改动，请先用原安装器还原，或通过 Steam 验证游戏文件。

## 主要功能

- 延续 v1.3 的480条人物闲聊精修，补全俚语、挖苦、双关和上下文信息。
- 采用荘臣等经典译名，补齐其他车手及12个额外别名。默认玩家昵称刘沛松可取消，已有昵称保留。
- 修复人物闲聊立绘、音乐MV标题乱码、地图公里数遮挡，以及音乐长标题重叠和播放状态越界。
- 音乐MV使用乐队名《歌曲名》格式，双语音乐标题使用英文原文加括号中文。长文字缩字、换行后仍超出时滚动显示。
- 补译开场出品、制作介绍和版权行，保留公司专名及游戏图形标志。

## 四项独立可选功能

| 功能 | 内容 |
| --- | --- |
| 音乐双语译名 | 乐队与歌曲名显示英文原文及中文译名 |
| 车辆译名 | 虚构品牌与车型中文名，涵盖菜单、标题、说明引用和座驾栏，保留排量与字母数字代号 |
| 游戏内五槽存档 | 游戏内选择、保存、读取、中文命名与F2重命名，使用原生RRS进度 |
| 保持比例的宽屏扩展 | 扩展赛事横向视野，提供宽屏菜单与渲染设置 |

四项默认关闭，可以分别安装、单独回退或组合使用。“管理已安装功能”可读取当前状态并应用变更。核心汉化通过主窗口“还原英文”回退。

## 存档管理

工具中的“导入／管理存档…”支持指定槽位导入、导出、重命名、清空及备份恢复。覆盖或清空前自动保留进度和名称。存档位于当前用户 LocalAppData 下的 RoadRash-Chinese/Saves，卸载模块后进度保留。

存档菜单自动检测已加载且已启用的宽屏组件。关闭宽屏时，五槽菜单位于中央4∶3区域。启用宽屏时，按实际窗口尺寸扩展布局。文字和按钮命中共用坐标，返回时先恢复游戏窗口焦点再关闭弹层。

玩家名称可在读取进度后进入“洗手间”→“玩家姓名”修改，再保存进度。

## 兼容性与验证

适配特定 Steam 周年版文件摘要。需要简体中文非 Unicode 程序代码页936，安装器会检查兼容条件。Windows 10、其他电脑与不同中文输入法仍待独立设备复核。

v1.5通过551项安装及管理断言、6273项存档布局断言、22项返回窗口交接断言、19项原生存档处理与10项音乐布局检查。安装组合覆盖四项可选功能的16种状态。

本机独立游戏副本已检查三组车店、车型标题和座驾栏，以及宽屏开关两种模式的存档显示、可见取消按钮点击、第一槽读取与另存取消返回。完整游戏内五槽读写、不同输入法、其他电脑和游戏内分辨率切换仍待复核。

完整包内附更新记录及五份译名对照表。车型名按玩家确认的方向采用意译，具体取舍见车型对照表。

## 源码与构建

当前正式安装器源码、原生模块源码和构建所需补丁数据位于 versions/v1.5。

```powershell
./versions/v1.5/build.ps1
```

使用 Windows .NET Framework 4.x C# 编译器，输出 versions/v1.5/dist/RoadRash_Steam_ZH_v1.5.exe。脚本使用随仓库提供的已构建模块及差分数据。原生模块源码位于 native，采用 Zig 0.15.2、x86-windows-gnu 编译。根目录保留v1.3构建结构。
