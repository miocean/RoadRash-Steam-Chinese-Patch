# 暴力摩托 Steam 简体中文补丁

适用于 **Road Rash: 30th Anniversary Edition（30周年纪念版）Steam 英文版**的非官方简体中文补丁。

**[下载 EXE 安装器（最新发布）](https://github.com/miocean/RoadRash-Steam-Chinese-Patch/releases/latest)**

## 安装与还原

1. 退出游戏，在 Steam 游戏属性中将语言设为 **English**。
2. 在 Releases 下载 `RoadRash_Steam_ZH_v1.2.exe`，双击打开。
3. 点击“浏览…”选择游戏目录，或直接粘贴路径。应选中包含 `RoadRash95.exe` 和 `TEXT` 文件夹的根目录。
4. 点击“检查目录”，确认版本匹配后点击“安装汉化”。
5. 从 Steam 正常启动游戏。

需要还原时，退出游戏，用同一安装器选择相同目录，点击“还原英文”。原始文件备份在游戏目录的 `Codex-ZH-backup-v1/ENU.DLL`，请保留。

安装器会校验游戏版本、内置补丁和原始备份，遇到不匹配的文件会停止。只替换 `TEXT/ENU.DLL`，不替换游戏主程序，不修改系统设置。兼容此前 v1.0 脚本安装器创建的备份。

## 汉化范围

- 977条译文，其中包含480条人物对话。
- 主要菜单、人物介绍、赛道提示、车辆介绍、设置、比赛与结算提示。
- 部分制作名单标题和职务。

车辆品牌和型号、乐队和歌曲名、制作人员姓名、版权与音乐授权文字保留原文。图片招牌、视频画面和语音未改动；不含视频字幕或中文配音。部分由主程序提供的系统文字可能仍为原文。

## 兼容性与验证

针对2026年11月6日制作时的 Steam 周年版文件进行适配，安装器使用SHA256校验具体版本。需要简体中文非 Unicode 程序环境（系统代码页936）。v1.2会拒绝1252、UTF-8/65001等其他代码页下的安装，防止游戏乱码；还原英文不受此限制。安装器不会更改系统区域设置。

## 源码与构建

`src/` 为 C# Windows Forms 安装器源码，`translations/` 保存译文，`payload/ENU.DLL` 为已翻译的语言资源，构建时会嵌入EXE。

Windows 自带的 .NET Framework 4.x C# 编译器可用于构建：

```powershell
./build.ps1
```

输出：`dist/RoadRash_Steam_ZH_v1.2.exe`。无需额外安装打包工具。译文表用于审校和后续维护；修改译文表后需要重建语言资源，并同步安装器中的补丁摘要。
