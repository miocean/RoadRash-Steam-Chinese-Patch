# 安装器测试

`InstallerTests.cs` 使用与图形界面相同的 `PatchEngine`，在调用者明确提供的独立测试目录中演练安装与还原。不要将真实游戏目录作为测试输出目录。

测试覆盖内置资源摘要、只读检查、首次安装、原始备份、重复安装、还原、重复还原、错误目录、主程序版本不匹配、备份冲突、其他语言文件保护、文件占用及暂存清理、代码页限制，以及主程序更新后仍能还原，共32项断言。

参数依次为：原版游戏目录、独立测试输出目录、原始英文ENU.DLL文件路径、旧版v1.0至v1.2汉化ENU.DLL路径。测试会复制主程序作为版本校验样本，不执行主程序，也不修改输入目录。

本机已全部通过；实际游戏抽查范围和未验证部分见仓库README。

`LayoutTests.cs` 使用真实WinForms控件，模拟100%、125%、150%、200%尺寸与字体缩放，检查标题大小、结果框首行与第二行、长文本滚动、底部说明高度以及控件之间的布局边界。参数为截图输出目录。RichTextBox不支持DrawToBitmap绘制文字，所以导出图片只用于检查布局；实际文字显示另在可见窗口检查。这不等于在四种操作系统DPI配置下分别实测。

新增24个立绘副本、旧版升级、失败回滚、同名文件保护和还原所有权检查。输出目录须为全新空目录，重复运行请另选目录。测试会复制主程序和原图，不执行游戏。

Verify-Language.ps1 -OriginalDll <英文原版ENU.DLL> 使用Windows资源API校验1408个槽、977条译文的GBK编码及格式占位符。原件严格按SHA256校验。
