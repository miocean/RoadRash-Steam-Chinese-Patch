# v1.3 闲聊审译说明

480条闲聊按Steam英文逐条复核，尽量保留信息、人物口吻和笑点。旧姓名会遮住英文姓名的双关，因此必要时在台词里补出“鲈鱼”“不粘锅”等线索。中文措辞与英文笑点无法总是一一对应，本文件记录重点处理及解释性质的取舍。

| ID | 难点 | 处理 |
| --- | --- | --- |
| 508、513 | 外冷内热套话的反转 | 里面仍是一颗“石头心”，保留反转。 |
| 554 | 男朋友的铁链与狗链 | 明确“不是我拴着他的狗链”，保留支配关系的笑话。 |
| 574 | 甩掉恋人 / 打倒；2×4木料 | “拿根二乘四英寸的木方，把你永远甩掉”，保留双重威胁。2×4是木料标称规格。 |
| 575 | flyboy与fly | 按“飞行员”俚语处理，再接“像只苍蝇”的外貌挖苦；不使用无依据的“风流小子”。 |
| 598、775、790 | Bass姓氏亦为鲈鱼；串鱼、煎鱼、钓鱼 | 使用旧名露西亚，同时补出鲈鱼。598保留鱼挂久了发臭；775同时表达更重要的事要办，避免只剩字面煎鱼。 |
| 606 | “伤害所爱的人”的反转 | 译为“不爱你，也照样揍”，稍作显化以免误读为放过对方。 |
| 638、915 | club既是俱乐部也是棍子 | 结合持棍车手和威胁语境，分别用“拿棍子欢迎入会”“棍子俱乐部”提示双关；这是语境解释。 |
| 678 | 保住面子 / 保住脸 | 保留“面子”和打到认不出脸的关联。 |
| 689、696 | squid为摩托车圈菜鸟称呼 | 用“菜鸟”，保留和小狗受惊尿身的嘲弄；未硬译成鱿鱼。 |
| 701、708 | quarters | 明确25美分硬币，避免误作人民币“两毛五”。 |
| 748、753 | 朋克家庭转而崇拜华尔街 | 保留莫西干头、华尔街与“信仰”，不改成普通发财经历。 |
| 811 | 拳打三次 / 棒球三振 | 用“三振出局”，保留运动术语与打架的重叠。 |
| 862、971、973 | Teflon绰号 / 什么都不粘 | 在相关台词中使用“不粘锅迈克”，保留粘住名声、纠缠等双关；正式姓名仍是迈克。 |
| 934 | 货物超宽红旗的笑话 | 保留后裤兜红旗，补出“注意超宽”使中文读者理解。 |
| 937 | blue blood贵族血统 / 真正的蓝血 | 同时写出贵族与流血，保留威胁。 |
| 954 | 摸透底细 / 死期到了 | 分别表达两个number习语，优先保留完整意思。 |
| 961 | reach puberty | “进入青春期”，不是“过了青春期”。 |
| 977、984 | 清晨气味的电影台词式戏仿 | 保留清晨和燃烧机油气味的句式，不另塞入原文没有的片名。 |

词义核对：[flyboy（American Heritage）](https://ahdictionary.com/word/search.html?q=flyboy)、[stringer（Cambridge）](https://dictionary.cambridge.org/us/dictionary/english/stringer?topic=hunting-and-fishing)、[quarter（Cambridge）](https://dictionary.cambridge.org/us/dictionary/english/quarter)。梗的具体意图如无作者说明，只能结合台词和角色语境判断。

资源读回和占位符校验只能证明补丁包含预期文本，不能证明翻译完美。游戏内抽查不能代替480条台词逐屏验收；目前没有完整通关和全量画面验收记录。

本版按用户偏好，在10条台词中少量采用现代中文玩家用语，如835的愤怒用‘红温’、875越来越凶险用‘上强度’、590寻求注意用‘刷存在感’。只调整表达，不添加现实人物、热点事件或改变人物关系。
